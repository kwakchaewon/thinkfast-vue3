# 프론트엔드 인프라 구성 리포트

**작성일**: 2025-11-20  
**대상**: 인프라팀 논의용  
**프로젝트**: ThinkFast Frontend (Vue3 + Nginx)

---

## 1. 작업 개요

Vue3 프론트엔드 애플리케이션을 Docker 컨테이너로 패키징하고, Nginx를 통한 정적 파일 서빙 및 백엔드 API 프록시를 구성했습니다.

**구현 내용**:
- 멀티 스테이지 Dockerfile 구현
- Nginx 기반 정적 파일 서빙 및 API 프록시 구성
- SPA 라우팅 지원 (Vue Router History 모드)
- 정적 파일 캐싱 최적화
- 보안 헤더 및 Gzip 압축 적용
- 환경별 API URL 동적 설정

---

## 2. 구현된 아키텍처

```
Stage 1: Build (node:18-alpine)
  ↓ npm ci, npx vite build
  ↓ /app/dist 생성

Stage 2: Production (nginx:alpine)
  ↓ /app/dist → /usr/share/nginx/html 복사
  ↓ nginx.conf 템플릿 복사
  ↓ 환경 변수 자동 치환

런타임:
브라우저 → Nginx (포트 80)
  ├─ 정적 파일 서빙 (/)
  └─ API 프록시 (/api/*) → 백엔드 서버
```

---

## 3. 주요 구성 요소

### 3.1 Dockerfile

**Stage 1: Build Stage**
- 베이스 이미지: `node:18-alpine`
- 의존성 설치 후 Vite 빌드 실행
- 빌드 결과물: `/app/dist`

**Stage 2: Production Stage**
- 베이스 이미지: `nginx:alpine`
- 빌드 산출물을 `/usr/share/nginx/html`로 복사
- `nginx.conf`를 템플릿으로 복사
- 환경 변수 자동 치환 (nginx:alpine 기본 기능)

### 3.2 Nginx 설정 (nginx.conf)

**정적 파일 서빙**
- 루트 경로: `/usr/share/nginx/html`
- SPA 라우팅: `try_files $uri $uri/ /index.html`
- HTML 캐싱 비활성화 (최신 버전 보장)

**정적 파일 캐싱**
- CSS/JS: 1년 캐시, `immutable` 설정
- 이미지/폰트: 1년 캐시

**백엔드 API 프록시**
- 프록시 경로: `/api/*`
- 백엔드 URL: 환경 변수 `${BACKEND_URL}` 사용
- 헤더 전달: `X-Real-IP`, `X-Forwarded-For`, `X-Forwarded-Proto` 등
- WebSocket 지원
- CORS Preflight 자동 처리

**보안 설정**
- 보안 헤더: `X-Frame-Options`, `X-Content-Type-Options`, `X-XSS-Protection`, `Referrer-Policy`
- 숨겨진 파일 접근 차단

**Gzip 압축**
- 압축 레벨: 6
- 대상: 텍스트, JSON, JavaScript, CSS, XML, SVG

### 3.3 Vite 빌드 설정 (vite.config.ts)

- Base Path: `'/'` 명시적 설정
- 청크 분할: `vendor` 청크로 그룹화 (순환 참조 방지)
- Chart.js 별도 청크 분리
- 빌드 최적화: ES2020 타겟, CSS 분할, esbuild minify

### 3.4 Axios API 설정 (src/apis/axios.ts)

- 프로덕션: `BASE_URL = '/api'` (Nginx 프록시 사용)
- 개발 환경: `BASE_URL = 'http://localhost:8080'`
- 액세스 토큰 자동 추가
- 401 에러 시 자동 토큰 갱신

## 4. 환경 변수

| 변수명 | 기본값 | 설명 |
|--------|--------|------|
| `BACKEND_URL` | `http://thinkfast-backend:8080` | 백엔드 API 서버 URL |
| `NGINX_HOST` | `localhost` | Nginx server_name |
| `NGINX_PORT` | `80` | Nginx 리스닝 포트 |

컨테이너 실행 시 환경 변수로 오버라이드 가능합니다.

## 5. 문제 해결 과정

### 5.1 빌드 단계 문제
- **문제**: GitHub Actions에서 `npm run build` 실패 (vue-tsc 타입 체크 오류)
- **해결**: Dockerfile에서 `npx vite build` 직접 실행으로 변경

### 5.2 하얀 화면 문제
- **문제**: 배포 후 브라우저에서 하얀 화면만 표시
- **해결**: `vite.config.ts`에 `base: '/'` 명시적 설정

### 5.3 JavaScript 런타임 오류
- **문제**: `Uncaught ReferenceError: Cannot access 'Y' before initialization` (모듈 초기화 순서 문제)
- **해결**: `vite.config.ts`의 `manualChunks` 단순화하여 모든 vendor를 단일 청크로 그룹화

### 5.4 API 프록시 경로 문제
- **문제**: 프로덕션에서 `/api` 프리픽스가 붙지 않음
- **해결**: `src/apis/axios.ts`에서 프로덕션 환경의 `BASE_URL`을 `/api`로 설정
