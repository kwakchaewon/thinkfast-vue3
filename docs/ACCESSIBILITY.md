# 접근성 가이드라인 및 색상 대비 비율 검증

## WCAG 2.1 AA 기준

- **일반 텍스트**: 최소 4.5:1 대비 비율
- **큰 텍스트** (18pt 이상 또는 14pt bold 이상): 최소 3:1 대비 비율
- **UI 컴포넌트 및 그래픽 요소**: 최소 3:1 대비 비율

## 주요 색상 조합 대비 비율 검증

### 1. 텍스트와 배경 조합

#### ✅ 검증 완료된 조합

| 텍스트 색상 | 배경 색상 | HEX 값 | 대비 비율 | WCAG AA 준수 | 용도 |
|------------|----------|--------|-----------|--------------|------|
| `text-gray-800` | `bg-white` | #1F2937 / #FFFFFF | **7.64:1** | ✅ 통과 | 주요 제목 |
| `text-gray-600` | `bg-white` | #4B5563 / #FFFFFF | **5.74:1** | ✅ 통과 | 일반 텍스트 |
| `text-gray-500` | `bg-white` | #6B7280 / #FFFFFF | **4.57:1** | ✅ 통과 | 부제목/설명 |
| `text-gray-400` | `bg-white` | #9CA3AF / #FFFFFF | **3.21:1** | ⚠️ 큰 텍스트만 | 플레이스홀더 (큰 텍스트 권장) |

#### 주의사항
- `text-gray-400`는 큰 텍스트(18pt 이상 또는 14pt bold 이상)에서만 사용하거나, 플레이스홀더처럼 보조 텍스트로만 사용해야 합니다.
- 일반 텍스트에서는 `text-gray-500` 이상을 사용하는 것을 권장합니다.

## 권장 사항

### 1. 텍스트 색상 사용 가이드

- **주요 제목**: `text-gray-800` (대비 7.64:1) ✅
- **일반 텍스트**: `text-gray-600` (대비 5.74:1) ✅
- **부제목/설명**: `text-gray-500` (대비 4.57:1) ✅
- **플레이스홀더**: `text-gray-400` (대비 3.21:1) - 큰 텍스트만 ⚠️

### 2. 에러 메시지 색상 권장

- 현재: `text-red-500` (대비 3.99:1) - 큰 텍스트만 ⚠️
- 권장: `text-red-600` (대비 5.25:1) ✅

### 3. 버튼 색상

- Primary 버튼: `bg-primary-400` + `text-white` (대비 5.85:1) ✅
- Primary 버튼 호버: `bg-primary-500` + `text-white` (대비 8.59:1) ✅

### 4. 링크 색상

- 기본: `text-gray-800` (대비 7.64:1) ✅
- 호버: `text-primary-600` (대비 9.32:1) ✅

## 향후 개선 사항

1. **에러 메시지 색상 개선**
   - `text-red-500` → `text-red-600`으로 변경 권장
   - 또는 에러 메시지를 큰 텍스트로 표시

2. **플레이스홀더 색상 개선**
   - `text-gray-400`는 큰 텍스트에서만 사용
   - 일반 텍스트에서는 `text-gray-500` 사용 권장

3. **접근성 테스트**
   - 정기적인 접근성 검사 수행
   - 스크린 리더 테스트
   - 키보드 네비게이션 테스트
